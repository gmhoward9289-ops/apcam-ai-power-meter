How these numbers were produced

  • Measured: GPU watts, VRAM and temperature; request start, duration, status, endpoint and client class; generation rates; model inventory and on-disk size.
  • Estimated: non-GPU system draw (the slider), the CO₂ factor (grid carbon intensity varies by region and hour; the slider is a flat average), and the assumption that the GPU holds its sustained wattage for a whole request. Short requests spend part of their time loading weights at lower draw, so their energy is mildly over-stated.
  • Rates are per model, not per request. The runner's internal task ids are non-contiguous and do not map one-to-one onto HTTP requests, so pairing a rate to a request would be guesswork. Rates are attributed only to the model loaded at the time, which the load timeline does establish.
  • Some tags cannot be told apart. Tags sharing a weights blob differ only in a parameters layer and are indistinguishable in the logs, so they appear as one entity.
  • Not measured: wall power, unless calibration used a smart plug (-PlugUrl). Otherwise only the GPU is instrumented and the gap to the outlet stays open.
  • Privacy: client addresses are reduced to a class and a short hash at capture time. The raw address is never written to disk.
